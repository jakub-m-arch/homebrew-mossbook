# Homebrew tap for Mossbook

[Mossbook](https://github.com/jakub-m-arch/mossbook) is a private, offline
well-being journal.

```sh
brew install --cask jakub-m-arch/mossbook/mossbook
brew upgrade --cask mossbook
```

The cask is updated automatically when a release is published. Uninstalling never
removes your journal (`~/Library/Application Support/io.github.jakubmarch.mossbook`).
